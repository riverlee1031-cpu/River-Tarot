- 三張牌陣：Past / Present / Future
- Love / Career / Money / General 主題
- 正位 / 逆位隨機
- 點擊翻牌動畫
- 核心牌義 + 主題解讀 + River Reading
- localStorage 抽牌紀錄
- 手機響應式介面
- Web Share API / 複製分享結果

## 部署
把此資料夾所有檔案上傳到 GitHub repository 根目錄，Settings → Pages → Deploy from a branch → main / root。
